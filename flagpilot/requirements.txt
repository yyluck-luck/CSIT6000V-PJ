# FlagPilot 的可选依赖。

# 为什么要单独一个文件而不是塞进 setup.py：这个项目的核心路径**只依赖标准库**

#
#   python3 -m pip install -r requirements.txt
#
# 装完用 `python3 -m flagpilot doctor` 确认哪几项真的生效了。
