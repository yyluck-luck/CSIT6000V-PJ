两种模式的区别

解题：模型每轮只能回一个 JSON 动作，产物进 runs/，参与 verified 统计。

答疑：模型正常说话，命令用 <run>…</run> 包起来由沙箱执行。 产物只用于讲解与自测，永不参与任何评分。

为什么这么分

讲解时直接给答案是合理的；但把它记进 verified 率就是把"背答案"算成"解出来"。 所以两条链路在落盘和统计上完全隔开。

存在哪（都在本地磁盘）

求解：runs/web/<run_id>/trace.jsonl 全事件 + 摘要； work/ 是沙箱现场，replay/ 是干净目录里的重放。

答疑：runs/chat/<session>/chat.jsonl 逐轮问答， 服务重启后回来还能接着聊。

记忆：runs/memory/tasks/<题名>.jsonl， 只记结论（verdict / 轮次 / 耗时 / 归因），不存 flag。
